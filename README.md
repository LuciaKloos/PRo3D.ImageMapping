This simple visualization tool can be used for visualizing and projecting HERA instrument data onto bodies (interesting is earth, moon, mars, deimos and finally dimorphos).

Soon we will add test images and screenshots showing the tool in action.

Building:
 - `dotnet tool restore`
 - `dotnet paket restore`
 - run the project src/PRo3D.ImageMapping


Supported platforms:
 - win, mac, linux

If you need a prebuilt contact us pro3d-support@vrvis.at.
